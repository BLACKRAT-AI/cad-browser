CAD Browser

A minimal Chromium browser tuned for CAD, CAM and WebGL work. No sync, no sign-in, no extensions, no telemetry.

What it does differently

Runs on the right GPU
Enumerates every adapter, picks the one with the most dedicated video memory, and asks Windows to run on it. Then it checks what is actually rendering and tells you when the two disagree.
Reports memory honestly
Installed, usable and hardware-reserved RAM from three independent sources, with per-slot detail and the motherboard maximum read from the firmware. Any disagreement is shown, not hidden.
Sleeps idle tabs
Background tabs are unloaded under memory pressure and reloaded on click. A restored session costs one renderer, not one per tab.
Blocks tracker hosts
A host list applied per request. First-party requests are never blocked.
Measures itself
An optional overlay shows real frame times, GPU load, video memory, CPU and tab counts, taken from the same counters Task Manager reads.
