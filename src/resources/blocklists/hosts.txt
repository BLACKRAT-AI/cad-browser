# CAD Browser - built-in host blocklist
#
# One host per line. "#" starts a comment. Hosts-file lines ("0.0.0.0 host")
# are also accepted so a list copied from elsewhere works unchanged.
#
# A listed domain also covers its subdomains: "doubleclick.net" blocks
# "stats.g.doubleclick.net". First-party requests are never blocked whatever
# this file says, so a site can never break itself through an entry here.
#
# This is a curated starting list of well-known advertising, analytics and
# session-recording networks. It is deliberately not a 100,000-entry dump:
# every entry here is one that is safe to block outright, and the size keeps
# startup parsing to a few milliseconds.
#
# To add your own, put them in:
#   %LOCALAPPDATA%\CADBrowser\blocklist.txt
# That file is read after this one and survives upgrades.
#
# Deliberately NOT blocked, because blocking them breaks real work:
#   googleapis.com, gstatic.com, jsdelivr.net, unpkg.com, cloudflare.com,
#   cdnjs.cloudflare.com, fontawesome.com, and any first-party CDN.
